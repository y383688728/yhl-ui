# yhl-ui

## 安装或更新

1. 在 Linux 服务器上准备 Docker、Docker Compose 和 Python 3.10+，并在 1Panel 安装并启动 OpenResty。
2. 将域名解析到服务器公网 IPv4。在 1Panel 为这个域名建好 HTTPS 网站，确认 `443` 能正常打开并启用证书自动续期。防火墙和云安全组放行 TCP `443`、`8080`、`9999`。
3. 登录服务器终端，运行下面这条命令，选择 **1）安装或更新**。已用 root 登录时，可以把 `sudo bash` 改成 `bash`。

```sh
curl -fsSL https://github.com/y383688728/yhl-ui/releases/latest/download/setup.sh | sudo bash
```

首次安装输入域名和后台路径，路径回车默认 `/admin`。保存终端最后显示的后台地址、账号和密码。以后更新用同一条命令，沿用原有配置。安装无需填写 1Panel API Key。

## 日常使用

- **添加设备**：在后台添加设备。Clash/Mihomo 使用订阅链接或「Mihomo 订阅码」，Shadowrocket 扫「小火箭节点码」导入单节点。订阅链接和二维码私下传递。需要让某条订阅失效时，在后台撤销对应设备。
- **分流规则**：在「Clash 分流规则」粘贴 `rules:` 段并保存，再在各设备上刷新 Clash/Mihomo 订阅。Shadowrocket 的分流规则在客户端设置。
- **查看用量**：点订阅旁的「流量详情」查看上传、下载和合计。多台设备共用一条订阅时合并统计。
- **登录安全**：在后台可修改密码并启用验证器。忘记密码时，运行上面的菜单命令，选择 **2）更新并重置管理员密码，关闭验证器**。

## 卸载

运行同一条菜单命令，选择 **3）完整卸载** 并确认。管理员、设备、订阅和统计数据会永久删除。1Panel 的 HTTPS 网站和证书会保留。\n
